
# Modos de trabajo y cómo crear archivos

En `vi` no escribes directamente como en Word. El editor cambia de "modo" según lo que quieras hacer.

* **Modo Normal:** Es para dar órdenes (borrar, moverte, copiar). Presiona `Esc` para volver aquí siempre.
* **Modo Inserción:** Es para escribir texto normalmente. Entras presionando la tecla `i`.
* **Modo Comando:** Es para guardar o salir. Entras escribiendo dos puntos (`:`).

Para crear o abrir un archivo desde la terminal:
```bash
vi mi-archivo.txt
