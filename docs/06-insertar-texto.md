# Formas de empezar a escribir

No solo existe la tecla `i` para empezar a escribir texto:

* `i` - Empieza a escribir **antes** de donde está el cursor.
* `a` - Empieza a escribir **después** del cursor.
* `o` - Abre una **línea nueva abajo** y empieza a escribir.
* `A` - Salta directo al **final de la línea** para escribir.
